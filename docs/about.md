## Projects Delivered

### 1. Manage Business Platform — 75Way Technologies

A centralized authentication and user management platform delivered to a client of 75Way Technologies. The platform provides a unified identity, access, logging, and subscription management layer that can be integrated into multiple internal products of the client organization.

- **Modules:** Authentication, User Management, Access Control, Activity Logs, Subscription Management
- **Primary Ownership:** Subscription Module and Access Management Module
- **Tech Stack:** Next.js (App Router), MongoDB, Mongoose ODM, custom NextAuth.js setup, Tailwind CSS
- **Methodology:** Agile, 3-member team, GitHub pull request-based code reviews

### 2. Training Letter Management Plugin — GNDEC Moodle

A custom Moodle local plugin (`local_training_letter`) that digitizes the industrial training letter application, approval, and verification workflow for the GNDEC Training and Placement Cell.

- **Roles:** Student, Teacher, Manager, Site Admin
- **Core Features:** Dual-approval state machine, department-scoped teacher visibility, auto-generated reference numbers in the format `GNDEC/[YEAR]/[ID]`, file security gatekeeper
- **Tech Stack:** PHP 8, MySQL via Moodle's `$DB` abstraction, Moodle Form API, Moodle File API

### 3. Training and Placement Portal — GNDEC

A full-stack web application that replaces the existing manual, Google Forms-based placement workflow with a single integrated platform managing the complete lifecycle of campus placements.

- **Roles:** Administrator, Recruiter, Student
- **Core Features:** Verification-based profile locking, system-managed and custom rounds, eligibility-based drive visibility, one-click Excel export with round-based filtering
- **Tech Stack:** Next.js 16 (App Router), React 18, PostgreSQL, Prisma ORM, NextAuth.js (JWT), bcrypt, Material UI, Tailwind CSS, ExcelJS
