# Week 1 — Joining and JavaScript Fundamentals

**Dates:** 5 January – 9 January 2026
**Location:** 75Way Technologies, Mohali
**Track:** Multi-stack Training — MERN

---

## Tasks Done

- Completed the joining formalities on the first day, including ID card collection, workstation allocation, and a brief orientation by the HR team covering company policies, working hours, the structure of the training programme, and the schedule of the evaluation test planned for the end of February.
- Met the assigned training mentor and the two co-interns who would be part of the same training batch for the next two months.
- Set up the local development environment on the assigned workstation, including installation of Node.js (LTS version), npm, and Visual Studio Code with the ESLint, Prettier, and Live Server extensions.
- Configured Git on the local machine, generated SSH keys, and linked them to the personal GitHub account that would be used for all training assignments and the project work later in the internship.
- Attended morning theory sessions on the foundations of web development, covering the structure of an HTML document, semantic tags, the box model in CSS, and the role of the browser's rendering engine.
- Practised basic page layouts in the afternoon hands-on sessions, building small static pages using HTML5 semantic elements and styling them with CSS, including the use of Flexbox and CSS Grid for responsive layouts.
- Began structured JavaScript learning from the second day onwards, covering variables (`var`, `let`, `const`), primitive and reference data types, operators, control flow, loops, and the practical difference between equality (`==`) and strict equality (`===`).
- Implemented functions in JavaScript using both the traditional function declaration syntax and the modern arrow function syntax, and explored the concept of first-class functions and higher-order functions.
- Worked through array and object manipulation, including destructuring, the spread and rest operators, and the most commonly used array methods such as `map`, `filter`, `reduce`, `find`, and `forEach`.
- Solved a set of mentor-assigned practice problems on string manipulation, array transformations, and basic object operations to consolidate the day's concepts.
- Pushed the day's exercises to a personal GitHub repository at the end of each day, getting into the habit of small, descriptive commits from the very first week.

## Learnings

- Understood that semantic HTML is not merely a style preference but improves accessibility, search engine indexing, and the readability of the markup for other developers.
- Realised how powerful Flexbox and CSS Grid are compared to the older float-based and table-based layout techniques, and that the two are complementary rather than competing.
- Picked up the subtle but important difference between `let` and `const` in terms of reassignment versus mutability, and why `var` should be avoided in modern JavaScript.
- Learned the practical value of arrow functions, particularly in callbacks and array methods, and understood that they do not bind their own `this` context.
- Got first-hand experience of how array methods like `map`, `filter`, and `reduce` lead to more declarative and readable code than traditional `for` loops.
- Picked up the basic Git workflow of `init`, `add`, `commit`, and `push` and understood the importance of writing clear commit messages from the very first commit.
- Observed that the morning theory plus afternoon practice format reinforces concepts effectively, as each idea is immediately applied to small but concrete coding tasks.
